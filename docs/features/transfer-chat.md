# 传输与聊天

> 关联决策: [ADR-0003](../adr/0003-chat-persistence-node-sqlite.md)

## 概述

局域网传个文件常要绕道 U 盘或网盘,一段文本更是没有轻量通道。Transfer 把文本与文件统一为聊天气泡流:选中设备即可像 IM 一样互发,记录本地保存。

## 能力

- 发送文本:即时送达并显示,对方无需确认
- 发送文件:支持一次多个(并行传输),自带完整性校验
- 文件大小不设人为上限:能不能传取决于对方的可用磁盘空间,不取决于网速或本机内存;链路慢只是传得久,不会因为传得久而失败
- 接收确认:文件以气泡形式等待接收/拒绝;可开启自动接收——小于阈值的文件自动收(默认关,全部文件需确认;文本始终自动接收)
- 聊天历史本地持久化,重启后仍在
- 消息流视口跟随:自己发出的消息(文本/文件/图片)一定停在最新;翻看历史时收到对方的新消息**不会**被拽回底部,改为右下角浮出「跳到最新」圆形按钮(期间有新消息则带未读圆点),点击回到底部
- 接收的文件与图片落**接收文件夹**(默认系统下载目录,可在设置里更改);文件气泡可一键定位到所在文件夹;图片气泡可预览、右键用系统程序打开
- 传输进度实时显示:传输中显示实时速度与已用时间,传输结束后保留总耗时(升级前的历史消息没有这个数据,不显示)
- 发送失败给出明确原因而非笼统"失败",按来源分四类:
  - **对方状态**:对方已离线 / 对方正忙 / 对方未在监听 / 对方处理时出错
  - **连接与信任**:连接超时(如对方开 VPN 全隧道,约 10 秒内提示,不长时间挂起)/ 证书不匹配 / 网络错误
  - **协议兼容**:对方无法识别本次请求(版本可能不兼容)/ 对方开启了 PIN 校验(当前版本尚不支持)/ 请求过于频繁,请稍后再试
  - **本地文件**:文件已不存在或被移动 / 没有读取该文件的权限
  只有确实认不出的错误才回落到"网络错误",不再把上述各类一律说成网络问题
- 不支持发送文件夹(含 macOS 的应用程序包等"看起来是单个文件"的目录):选中后该条会明确提示"暂不支持发送文件夹",同批选中的普通文件不受影响、照常发送
- 接收失败同样给出明确原因:磁盘空间不足、文件校验失败
- 聊天输入区支持直接截图与粘贴图片发送

## 边界与不做

- 不做断点续传;不做独立的传输历史页面(历史即聊天流)
- 大文件传输中断需整体重发
