# 接收文件夹

> 关联决策: ADR-0022

## 概述

收到的文件默认存进系统下载目录,而那里通常已经堆满了浏览器下载的东西,收件混在里面不好找。
本功能让你把接收文件夹指到自己想要的位置,并在那个位置变得不可用时自动改回默认,不让文件收不到。

## 能力

- 设置的「存储」分区显示当前接收文件夹的完整路径,点右侧按钮在文件管理器中打开它。
- 点「更改…」用系统选择器指定任意一个你有写入权限的文件夹。
- 选定后**立即生效**,不需要再点「保存」;这一页的「取消」也不会把它改回去。
- 使用自定义文件夹时会出现「恢复默认」,点它改回系统下载目录。已经是默认时不显示这个入口。
- 选到写不进去的文件夹会当场被拦下并说明原因,接收文件夹保持原样。
- 改完文件夹后提示:之前收到的文件仍在原来的位置,应用不会移动它们。
- 更改只影响之后的传输;正在进行的传输仍存到原来的位置。
- 你选的文件夹被删除、改名或所在磁盘被移除时,接收文件夹**自动改回系统下载目录**,
  文件照常能收到。设置里会留下一条提示说明发生了什么,直到你点「知道了」或重新选择才消失。
- 路径太长时省略号出现在左侧,保留末尾的文件夹名。

## 边界与不做

- 改文件夹**不会搬移**已经收到的文件,它们留在原来的位置。
- 自动改回默认之后,原先选的那个位置**不会被记住**——即使它后来又能用了(比如把移动硬盘插回来),
  也需要重新选一次。
- 没有"每次接收都问我存到哪里"的选项。
- 从 Mac App Store 安装的版本,首次选定文件夹后应用会记住授权;若该授权失效,
  表现与文件夹不可用相同(自动改回默认并提示)。
