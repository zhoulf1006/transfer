# 截图副本必须落持久目录,发送成功后不删

> 领域:截图 → 发送链路 · 文件生命周期

## 症状

发送端的图片消息不显示缩略图,回退成通用文件图标(接收端正常)。

## 根因

早期把截图写进 `temp/`,`sendFiles` 一 resolve 就 `unlink` 删除。

但**发送方消息的 `filePath` 指向的正是这个文件**——UI 的缩略图、看大图、另存为全部按 `filePath` 读盘。文件已删 → 读空 → `nativeImage.isEmpty()` → 回退成文件图标。

"发完就删"看起来是合理的清理,实际上删掉的是**自己消息记录的数据源**。

## 做法

落 `userData/sent-images/`(持久目录,非 temp),**成功保留、失败才删**——失败的消息没有保留价值,删副本免碎片。

## 已知 tradeoff

副本会随发送累积,清理策略(如 LRU)尚未做。改回 temp 或加"发完即删"会直接重现上述 bug。
