# 落地页的部署形态(一份代码两处部署)

> 关联: ADR-0011(移除 Gitee 镜像) · ADR-0017(落地页进大陆节点,下载源不动)
> 运维步骤见 `docs/ops/`,本文只写需求全景与边界。

## Problem Statement

落地页目前只部署在 Cloudflare Pages(`transfer.aloongplanet.com`)。ADR-0011 已实测坐实:**不备案的 Cloudflare 不接大陆节点**,大陆用户打开落地页要绕境外,首屏慢。

现在 `aloongplanet.com.cn` 已完成 ICP 备案、自有 ECS 已配好反向代理与证书,具备了让大陆用户从境内节点打开落地页的条件。

## Solution

**同一份落地页代码构建两次,部署到两个域名。** 两份产物只有一处差异:国内那份的页脚多一条 ICP 备案号(法规要求)。下载源、文案、结构、样式全部相同。

大陆用户因此拿到快的**页面**;**下载仍走境外**——安装包在未备案的 R2 上,这一半没有改变(见 ADR-0017 的「后果」)。

## User Stories

1. As a 大陆访客, I want 落地页从境内节点快速打开, so that 我不会因为白屏先离开。
2. As a 大陆访客, I want 在页脚看到备案号并能点击核验, so that 我确认这是合规站点。
3. As a 站主, I want 两处部署共用同一份代码, so that 改一次文案两边都更新,不会随时间分叉成两个站。
4. As a 站主, I want `.com` 那份**不出现**中国备案号, so that 它对境外访客既不突兀也不误导。
5. As a 站主, I want 国内站上线完全不影响已在跑的 Pages 部署, so that 不必为了新增一个部署去动旧的。
6. As a 站主, I want 一条命令完成国内站的构建与同步, so that 发版时不用回忆步骤。
7. As a 大陆访客, I want 下载按钮照常可用(哪怕慢), so that 镜像站不是个只能看不能下的残废站。

## 失败模式与边界

### 备案号的渲染

| 情形 | 预期行为 |
|---|---|
| 环境变量未设置(`.com` / Cloudflare Pages 构建) | 该项**整个不渲染**——不是渲染成空、也不是留一段空白间距。判据是**页脚高度与改动前一致**,而不是"看不见就行" |
| 环境变量已设置且合法(国内构建) | 在页脚同一行的品牌与链接之间出现,链接指向工信部核验页,**页脚高度不变** |
| 环境变量设置了但**格式非法** | **构建失败**。可选与"随便写什么都行"是两回事:写错的备案号是违规展示,静默放行等于把违规藏到线上,而线上没人会去看页脚 |
| 环境变量**存在但为空串或纯空白** | 视同未设置,不渲染、不报错。CI 与托管平台常把"没填"的变量传成空串,把它当非法值会让 `.com` 那侧莫名其妙构建失败 |
| 英文页 `/en/` | **同样渲染**。备案是对域名的要求,与页面语言无关 |
| **首页以外的页面**(隐私政策页及其英文版) | **同样渲染**。备案要求针对整个网站,不是单个页面;这些页面共用同一个页脚,因此是自动满足的——但必须实际验过,不能假设 |
| 窄屏 | 页脚三项按 flex 换行自然堆叠(品牌与备案号同行、链接落到下一行)。备案号**不得被截断、不得溢出容器**,页面不得出现横向滚动 |
| 深色主题 | 分隔线与文字颜色走既有 CSS 变量,不硬编码色值 |

### 下载与统计(与既有功能的回归点)

| 情形 | 预期行为 |
|---|---|
| 在国内站点下载 | 走与 `.com` **完全相同**的 R2 URL。本轮不引入任何按站点分流的下载逻辑 |
| 国内站的 origin 不在 R2 的 CORS 白名单里 | 统计请求被拒 → 按既有行为**静默隐藏统计行**,页面其余部分完全正常。这是既有的失败模式,不是本轮引入的新缺陷 |
| 白名单补上之后 | 统计行正常出现,无需改代码或重新部署 |
| R2 下载慢或超时 | 浏览器自身行为,本轮不干预(见 Out of Scope) |

### 构建与部署

| 情形 | 预期行为 |
|---|---|
| Cloudflare Pages 侧不设任何新环境变量 | 构建照常成功。**新增的读取逻辑不能让旧部署失败** |
| CI 跑 site 构建时不设环境变量 | 同上,必须绿 |
| **部署国内站时忘了设备案号变量** | 不允许发生。部署命令**自己保证**备案号被注入,而不是依赖使用者记得先 `export`——靠人记得的合规约束等于没有约束。真忘了(比如手工绕过该命令)时,构建出的产物应当在部署自检中被发现 |
| 部署脚本收到的不是构建产物目录 | **报错退出**,不能把错误内容推上服务器 |
| 同步后文件权限 | 必须在服务器侧显式修正。服务器 umask 会让新文件落成 640,反代容器里的 nginx 用户读不到会返回 403 |
| 同步时旧文件被删除 | 用 `--delete`,避免上一版的孤儿文件留在服务器上 |

### 引入内容带来的能力

本轮新增的唯一外部输入是**构建期环境变量**,它的值会进入 HTML。逐点核:

| 交互面 | 行为归宿 |
|---|---|
| 备案号文本插入 HTML | 走模板表达式,由框架转义;不使用任何原样注入 HTML 的写法 |
| 备案号链接的目标 | **固定常量**(工信部核验页),不由环境变量决定——否则就成了可被构建环境操纵的开放重定向 |
| 链接的打开方式 | 新标签打开,带 `rel="noopener"`,与页脚其它外链一致 |

## Implementation Decisions

- **备案号通过构建期环境变量注入**。国内构建设置它,Cloudflare Pages 不设。这样两边代码一字不差,Pages 控制台也不用改。
- **可选,但一旦设置就必须合法**。未设 → 不渲染;设了但格式不对 → 构建失败。这与个人主页那边"必填否则构建失败"的语义**相反**,照抄会让 `.com` 的构建挂掉。
- **备案号不进 i18n 字典**。它是法规信息,不翻译;且是专有值,不是文案。
- **页脚布局(来自已确认的原型)**:**不另起一行**。备案号作为页脚那一行的第三项,落在品牌与链接之间,由既有的两端对齐自动把它推到中间。字号小于产品链接、用弱化前景色——它是页面的法律附注,层级低于产品链接。`.com` 构建下该项**整个不存在**,页脚退回「品牌 | 链接」两端对齐,与改动前逐像素一致(实测两种状态页脚高度同为 26px)。
- **部署走手动脚本**,一条命令完成构建 + 同步 + 服务器侧权限修正 + 自检。选它而不是 CI 自动部署的理由见 ADR-0017。
- **不引入 canonical / sitemap**。`astro.config` 的 `site` 字段当前没有任何消费者,本轮不给它造消费者;两个域名的重复内容问题一并留到真需要 SEO 时再议。

## Testing Decisions

**什么算好测试**:只测外部可观察行为。本轮新增的唯一有真实失败模式、且能被纯函数测到的东西是**备案号的校验**。

**seam**(取最高层、越少越好,理想为 1):

1. **备案号校验函数** —— 四种输入都要有真实的变红条件:未设 → "不渲染";**空串/纯空白 → 同样"不渲染"**(不是抛错);合法 → 原样返回;非法 → 抛错。抛错那一态是重点,它是"构建失败"这条合规约束的唯一自动化保障;空串那一态则是防止 `.com` 侧被误伤的关键。

**渲染级验证(非自动化,但必须执行)**:两种构建目标下页脚的实际形态(整行在/不在、位置在产品链接行之下、窄屏对齐方式、深浅色)用浏览器实测,断言必须是渲染级——量几何、确认"不渲染"时高度为 0 而非留白,**并且要有阴性对照**(未设变量时的形态若与设了一样,断言就没有意义)。

**prior art**:`site/src/download-statistics.ts` 的 `parseDownloadSummary` 是同款纯函数校验 + 表驱动测试;`site/src/i18n/ui.test.ts` 是键集合对齐的先例。断言粒度与命名风格对齐它们。

**已知覆盖缺口(诚实标注)**:"Cloudflare Pages 在不设环境变量时构建仍成功"这条**没有自动化测试**——CI 里的 site 构建不设该变量,等价于覆盖了这条路径,但那是间接证据,不是针对它的断言。

## Out of Scope

- **下载源搬迁到境内**。这是 ADR-0011 选项 3 的另一半,本轮明确不做;大陆下载速度不因本轮改变。
- **自动化部署**。放行 GitHub Actions 出口 IP 物理上不可行(7297 个网段);self-hosted runner 有把同机 Harbor 挤 OOM 的风险;OSS 中转多一个活动部件。落地页三周只改过 10 次,不值得。将来要做,OSS 中转是最干净的那条。
- **canonical / sitemap / 两域名重复内容的 SEO 处理**。
- **R2 的 CORS 白名单**。在 Cloudflare 控制台加,不是代码改动。
- **国内站的下载提速或提示文案**。先上线看真实反馈,不为想象中的慢提前做优化。
- **公安联网备案号**。尚未申请;号下来后与个人主页同样处理。

## Further Notes

- 目标机器与个人主页同一台 ECS,上面还跑着 Harbor / Nginx Proxy Manager / Portainer。**本轮任何改动都不得影响那些既有服务**:不抢宿主端口、不改 Docker 守护进程配置、不重启反代以外的容器。可用内存约 860MB,很紧。
- 开发机常驻 TUN 模式代理,会劫持系统解析器并对任意目标返回连接成功。**在本机做的网络连通性测试一律不作数**;验证从服务端(日志、抓包)或独立网络进行。
